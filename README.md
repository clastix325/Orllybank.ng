# Orllybank Resources Nigeria Ltd

A full stack website built for Orllybank Resources Nigeria Ltd, a Lagos based freight and vehicle importation company.

## Features
- Public facing site showcasing available car listings
- Password protected admin panel that lets the client add, update, and remove car listings without needing a developer to touch the code

## Tech Stack
- Netlify Functions (serverless backend)
- Netlify Blobs (data storage for car listings)
- Deployed on Netlify

## What I built
I designed and built the admin panel system so the client could manage listings independently. The admin password is authenticated server side via environment variables (not hardcoded), and listings are stored and retrieved using Netlify Blobs.
